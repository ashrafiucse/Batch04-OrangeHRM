# Batch04-OrangeHRM

Cypress automation testing project for OrangeHRM HR management system.

## Project Setup

```bash
npm install
```

## Running Tests

```bash
npx cypress open
```

## Project Structure

- `cypress/e2e/` - E2E test specifications
- `cypress/e2e/Login/` - Login functionality tests
- `cypress.config.js` - Cypress configuration

## Configuration

- Viewport: 1280x720
- Cypress Version: 15.13.0
